## Highlights

- **VPS API** - the Virtual Private Server product is now available in the SDK, with server create/list/stop, offer and OS discovery. [#2414](https://github.com/scaleway/scaleway-sdk-python/pull/2414) · [commit 9ddc2e1](https://github.com/scaleway/scaleway-sdk-python/commit/9ddc2e142be3feb1e1f741486cb8db3e4056e82e)

  ```python
  from scaleway import Client
  from scaleway.vps.v1 import VpsV1API

  api = VpsV1API(Client())
  api.list_servers()
  ```

- **Data Orchestrator API** - define and run workflow orchestrations from Python (workflow definitions, versions and runs). [#2404](https://github.com/scaleway/scaleway-sdk-python/pull/2404) · [commit 6863d0b](https://github.com/scaleway/scaleway-sdk-python/commit/6863d0b6d677236367054a5fcea72810f5061af5)

  ```python
  from scaleway.dataorchestrator.v1alpha2 import DataorchestratorV1Alpha2API

  api = DataorchestratorV1Alpha2API(Client())
  api.start_workflow_definition(workflow_definition_id="...")
  ```

- **Dataviz API** - manage Grafana deployments that visualize your metrics: create, upgrade, version and certificate management. [#2405](https://github.com/scaleway/scaleway-sdk-python/pull/2405) · [commit acc94dc](https://github.com/scaleway/scaleway-sdk-python/commit/acc94dc19ff4ec74a3c7967bf2f686d81a675d7e)

  ```python
  from scaleway.dataviz.v1alpha1 import DatavizV1Alpha1API

  api = DatavizV1Alpha1API(Client())
  api.list_deployments()
  ```

- **Instance dedicated pools** - reserve pools of dedicated servers and attach/detach servers, with server-type discovery and GPU info. [#2176](https://github.com/scaleway/scaleway-sdk-python/pull/2176) · [commit d77d8a6](https://github.com/scaleway/scaleway-sdk-python/commit/d77d8a674d9d2cd16b6c3111eb1ad730882af0b1)

- **File Storage snapshots** - snapshot any filesystem, restore it into a new filesystem, and manage snapshots with full CRUD. [#2285](https://github.com/scaleway/scaleway-sdk-python/pull/2285) · [#2388](https://github.com/scaleway/scaleway-sdk-python/pull/2388) · [commit baeb12a](https://github.com/scaleway/scaleway-sdk-python/commit/baeb12acc12c43d352babdb7ec3576b20aefd8fb) · [commit 6c899ae](https://github.com/scaleway/scaleway-sdk-python/commit/6c899ae8464d37fcbefe0557f66c45547b26a8da)

- **Key Manager key rotation** - list the rotation history of your keys and pass a `rotation_index` when deleting key material, so audited key-rollovers are fully scriptable. [#2158](https://github.com/scaleway/scaleway-sdk-python/pull/2158) · [#2159](https://github.com/scaleway/scaleway-sdk-python/pull/2159) · [commit feb9a43](https://github.com/scaleway/scaleway-sdk-python/commit/feb9a43c657dda24dbf850b0025fffd67773cb56) · [commit 855cccf](https://github.com/scaleway/scaleway-sdk-python/commit/855cccf4a241fc065b375d9587013944ee1eca7c)

## Breaking changes and migrations

- **Data Orchestrator**: the `s3` task type is renamed to `object_storage`. Update workflow definitions that reference the old task type. [#2499](https://github.com/scaleway/scaleway-sdk-python/pull/2499) · [commit e77cb08](https://github.com/scaleway/scaleway-sdk-python/commit/e77cb0843e21460cec000ff6e9adffe50f9d1369)
- **Instance**: `ServerType.hourly_price` is deprecated; stop reading it and move to the billing data sources. [#2469](https://github.com/scaleway/scaleway-sdk-python/pull/2469) · [commit c851634](https://github.com/scaleway/scaleway-sdk-python/commit/c85163418cffc7c52b0231a227e1b55c8c3b5af4)
- **k8s**: the deprecated `Cluster.available_container_runtimes` field is removed; read `kubelet_args` or the node pool runtimes instead. [#2215](https://github.com/scaleway/scaleway-sdk-python/pull/2215) · [commit 62dfbb5](https://github.com/scaleway/scaleway-sdk-python/commit/62dfbb559819e083a28f6a16b447e8c8c8ca3ef1)
- **Partner**: `siren_number` is removed from `CreateOrganization` and `Organization`; stop sending it when creating organizations. [#2166](https://github.com/scaleway/scaleway-sdk-python/pull/2166) · [commit fc15e30](https://github.com/scaleway/scaleway-sdk-python/commit/fc15e30fffb5fb946059d80106f68da18c0298a0)
- **Search**: the `ResourceType` enum value `DDL_DATALAB` is renamed to `DATALAB`; update any code matching on the old value. [#2264](https://github.com/scaleway/scaleway-sdk-python/pull/2264) · [commit 2aa7d77](https://github.com/scaleway/scaleway-sdk-python/commit/2aa7d77e1407671bebf0538053fdd74f5bce22cc)
- **Annotations**: the batch delete endpoints are deprecated; use the single-resource delete instead. [#2442](https://github.com/scaleway/scaleway-sdk-python/pull/2442) · [commit 3bf7c30](https://github.com/scaleway/scaleway-sdk-python/commit/3bf7c302a24d325e2e26913ca03a74072e8670d4)
- **Product Catalog**: the `input_duration` pricing unit is removed from the `PricingUnit` enum. [#2274](https://github.com/scaleway/scaleway-sdk-python/pull/2274) · [commit c32248f](https://github.com/scaleway/scaleway-sdk-python/commit/c32248f2005239624bd0abec10aaa0f7dd8d922b)
- **Message Queue / SearchDB**: the unneeded `deployment_id` field is removed from the volume model; pick either the server- or detached-IP kind when listing IPs instead. [#2349](https://github.com/scaleway/scaleway-sdk-python/pull/2349) · [commit 67ceddc](https://github.com/scaleway/scaleway-sdk-python/commit/67ceddc4dfb6299585d98a3432863839f2572c9a)

## Core

### SRN on resources

Resources across most products (account, block, file, flexible-IP, IAM, instance, interlink, k8s, key manager, secret, serverless-sql, VPC, VPC-GW, ...) now expose their Scaleway Resource Name (`srn`), so you can reference any resource in IAM policies and cross-product tooling without juggling ids and zones. [#2162](https://github.com/scaleway/scaleway-sdk-python/pull/2162) · [commit 8b98a28](https://github.com/scaleway/scaleway-sdk-python/commit/8b98a28129ace1279cb4ae426b82fdaa87352cf5)

### SRN integration for Message Queuing and SearchDB

Messages and search-database resources gain `srn` fields, completing the same story for these two products. [#2291](https://github.com/scaleway/scaleway-sdk-python/pull/2291) · [commit f87b3ba](https://github.com/scaleway/scaleway-sdk-python/commit/f87b3ba6471243a1478376859c0b177f9626860f)

### it-mil region and zone

The SDK knows about the new Milan region: use the `it-mil` region and `it-mil-1` zone through the `REGION_IT_MIL` and `ZONE_IT_MIL_1` constants. [#2161](https://github.com/scaleway/scaleway-sdk-python/pull/2161) · [commit 85d8331](https://github.com/scaleway/scaleway-sdk-python/commit/85d833100f9f8aee7a53316f2b1d4f51a98e7e4f)

## Account

### SRN support

Account resources expose their `srn`, so you can scope IAM to specific projects and users by name. [#2244](https://github.com/scaleway/scaleway-sdk-python/pull/2244) · [commit 19930bc](https://github.com/scaleway/scaleway-sdk-python/commit/19930bc75297148fc954fa9520777252f0d458ac)

The `passkey` authentication method is supported in audit events. [#2136](https://github.com/scaleway/scaleway-sdk-python/pull/2136) · [commit 4a2a0df](https://github.com/scaleway/scaleway-sdk-python/commit/4a2a0df927c37efdbe2f78b989ee28ac2d8a64de)

The audit `action` is reported as a typed enum instead of a free-form string, so matching and validation no longer rely on string literals. [#2124](https://github.com/scaleway/scaleway-sdk-python/pull/2124) · [commit 167ffed](https://github.com/scaleway/scaleway-sdk-python/commit/167ffedf63846750aa68b36da201577f641729e6)

## Bug fixes

- **Inference**: deployment SRNs were built from the wrong scope, producing invalid resource names; they are now derived from the deployment region. [#2496](https://github.com/scaleway/scaleway-sdk-python/pull/2496) · [commit ae624ee](https://github.com/scaleway/scaleway-sdk-python/commit/ae624ee41e15de079887a355400ee0ef5a585941)
- **Containers**: the `liveness_probe` field documentation was wrong, misleading callers about semantics; the description now matches the API. [#2427](https://github.com/scaleway/scaleway-sdk-python/pull/2427) · [commit 041b158](https://github.com/scaleway/scaleway-sdk-python/commit/041b158ba0fd43602a14e4f2e59be3a0efd40606)
- **Dedibox**: `list_available_os` returned a misconfigured OS list (available operating systems were wrong); the OS data is repaired and aligned with the console. [#2301](https://github.com/scaleway/scaleway-sdk-python/pull/2301) · [commit 00b3c2e](https://github.com/scaleway/scaleway-sdk-python/commit/00b3c2e544d0d183627cb782462a610e1b5c1433)
- **Search**: serverless-container resources were missing from the Search resource types, so they surfaced as unknown types; the types are now registered. [#2209](https://github.com/scaleway/scaleway-sdk-python/pull/2209) · [commit 6b8a745](https://github.com/scaleway/scaleway-sdk-python/commit/6b8a74530237e9851a23917cd11feaee8d763456)
- **Core**: a non-JSON error body raised `JSONDecodeError` instead of the actual API error, breaking every caller's error handling; the SDK now surfaces the HTTP error cleanly. [#2207](https://github.com/scaleway/scaleway-sdk-python/pull/2207) · [commit eaab921](https://github.com/scaleway/scaleway-sdk-python/commit/eaab9214995ccb8265f31ea9dfcf6829dd3fc5b9)
- **Edge services**: updating a WAF perimeter with exclusion rules over PATCH failed because the rules were sent unwrapped; they are now marshalled as a `WafExclusionRules` payload. [#2199](https://github.com/scaleway/scaleway-sdk-python/pull/2199) · [commit 9924a89](https://github.com/scaleway/scaleway-sdk-python/commit/9924a89ea6977e2d4e2dccb2f804a58c2ca6175c)
- **Account**: `DeleteProjectWithResources` did not mark the request as a body-aware method, so the delete body was not sent and the call could be rejected; the body annotation is fixed. [#2198](https://github.com/scaleway/scaleway-sdk-python/pull/2198) · [commit 4c02ecd](https://github.com/scaleway/scaleway-sdk-python/commit/4c02ecd77b964a1a41e7931db612d4a1d5457964)
- **Instance**: the `ListServerCompatibleTypes` RPC shipped without its public documentation; the description is now generated. [#2186](https://github.com/scaleway/scaleway-sdk-python/pull/2186) · [commit 5b94caf](https://github.com/scaleway/scaleway-sdk-python/commit/5b94caf967ff72dee93f325a6a7f9c0e73b98771)
- **Apple Silicon**: the user-configuration endpoint used the wrong URL, so `get_user_configuration` called a non-existent route; the URL is corrected. [#2160](https://github.com/scaleway/scaleway-sdk-python/pull/2160) · [commit a90778f](https://github.com/scaleway/scaleway-sdk-python/commit/a90778f5a8cd8aabf2a6156f712a39cefcd39490)
